股票資產 PWA v4.9｜每日線上匯率版
測試日期：2026-08-01（台灣時間）

一、本版新增
1. 每天第一次開啟 App，自動檢查 USD/TWD；同一天已嘗試過就不重複連線。
2. 頁首「↻」更新股價時，同時檢查今日匯率。
3. 市場資料狀態頁新增 USD/TWD 卡片、更新時間、錯誤原因與「立即更新」。
4. 線上更新失敗時保留上一個成功匯率，不影響股價更新與 IB 主策略。
5. 每日資產快照保存當日匯率、匯率日期與來源。
6. 歷史損益圖切換 NT$ 時，優先使用各日期快照匯率；舊快照缺少匯率時才使用目前匯率估算。
7. 保留手動修改 USD/TWD；手動輸入會標記為手動匯率。
8. Service Worker 對線上匯率 API 不做快取，app.js、app.css、pwa.js 仍採網路優先。

二、匯率來源
- 來源：ExchangeRate-API Open Access endpoint。
- 官方規格：無需 API Key、資料每日更新一次、允許快取並要求來源標示。
- App 已加入「Rates By Exchange Rate API」來源標示。
- 2026-08-01 線上驗證 endpoint 回傳 result=success，且包含 TWD、資料更新時間及下次更新時間。
