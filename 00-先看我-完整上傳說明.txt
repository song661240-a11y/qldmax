股票資產 PWA v6.0｜完整部署方式

一、GitHub Pages
1. 解壓縮「股票資產-PWA-v6.0-系統健康捷徑統一視窗.zip」。
2. 將 ZIP 內全部內容覆蓋到 GitHub qldmax 儲存庫根目錄。
3. 等 Actions → pages build and deployment 出現綠勾。
4. 手機重新開 App；看到「發現新版 v6.0」就按「立即更新」。

二、Firebase Rules
本版 firestore.rules 與 v5.9 相同，沒有新增規則。
只要 v5.8 Revision Rules 已經 Publish，本次不用再到 Firebase 發布。

三、升級後快速驗證
1. App 標題應顯示 PWA v6.0。
2. 首頁「系統健康」若有異常，會出現「直接處理」區塊。
3. 點「更新 200SMA」應直接進「設定 → 市場資料」。
4. 點「更新 FT」應直接進「設定 → FT、複委託與台股」。
5. 點「查看自動快照／立即檢查同步」應直接進「設定 → 雲端同步與系統」。
6. 打開「快速更新」、「帳戶資產明細」、「回收區」，底部主要操作鍵應固定可見。
7. 任何刪除、還原、重置、解鎖等確認都應使用 App 自己的視窗，不再出現瀏覽器原生 confirm/prompt。

四、策略
Risk-On +4%、Risk-Off -3%、HOT 19/24/28 與正式執行核心均未修改。


v6.0 重點：首頁「系統健康」出現需處理項目時，直接點該項即可跳到對應設定的實際按鈕／區塊並短暫標示；雲端自動化頁亦提供 GitHub Actions 直接連結。
